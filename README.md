## 6\. 평가 방식 요약

* **평가 단위**: 사출 1회 (좌우 두 행을 같은 시각 1행으로 합치고, 하나라도 불량이면 불량)
* **시간 구조를 지킨 분할**: 같은 사출, 같은 연속 기록 구간은 항상 같은 쪽
* **rg3**: 5묶음 중 시험지 1개를 빼고 나머지 4묶음으로 모의고사 4번 → 라운드 1등만 시험지 채점 (5라운드)
* **cn7**: 불량 사건이 1번뿐이라, 불량 0 \~ 13개를 본 시점마다 그 이전 사출로만 학습하고 이후 사출을 탐지하는 조기경보 실험
* **기준선**: 학습에 쓴 사출의 점수는 쓰지 않고, 학습 데이터 안에서 빼고 학습한 정상 사출 점수(OOF)의 상위 0.5 / 1 / 2 / 5%
* **선택 규칙**: 실행 전에 확정 (rg3: PR-AUC → F1 → 단순한 쪽 / cn7: 컷 1 \~ 5 평균 재현율 ≥ 0.5 → 오탐률 → F1 → 단순한 쪽)
* **후보 9개**: 로지스틱 회귀, SVM, 랜덤포레스트, XGBoost × {기본, 하이브리드(공정 변수 + 이상점수)} + 비지도 단독(Isolation Forest)

## 7\. 결과 요약

* **최종 모델**: rg3 = Isolation Forest 비지도 단독, cn7 = 로지스틱 회귀(기본)
* 시간 구조를 지킨 평가에서 두 금형 모두 찍기 수준의 성능 (같은 모델로 랜덤 분할 시 cn7 PR-AUC 0.29 \~ 0.46 → 시간 분할 0.04 \~ 0.07)
* 주요 실패 조건: 묶음·날짜별 운전 수준 이동, 한쪽 칸에만 생기는 불량(rg3 25개 전부), 미래 기간 스크류 평균 회전수 기록의 1/10 변화

## 9\. 최종 모델 사용법

`output/final/`에 금형별 최종 모델(`final\_{cn7,rg3}.joblib`)과 입력 범위(`range\_{cn7,rg3}.json`)가 저장되어 있습니다.
노트북 11번의 `predict\_new` 함수로 KAMP 원본 형식의 새 데이터를 판정할 수 있습니다.

```python
pred = predict\_new(raw\_df, 'rg3')   # raw\_df: KAMP 원본 형식 (좌우 행 포함, TimeStamp 필요)
# 결과: t(시각), score(점수), 판정(불량/재검사/통과/판정보류), 보류사유
```

1. 좌우 행을 사출 1행으로 합침
2. 입력값이 학습 범위(대회 범위 최소 \~ 최대를 양쪽 10% 확장)를 벗어나면 "판정보류"
3. 나머지는 점수와 3단계 판정 (정상 상위 0.5% 기준선 이상 = 불량, 0.5 \~ 2% = 재검사, 나머지 = 통과)

※ 저장된 모델은 노트북의 `Candidate` 클래스를 사용하므로, 노트북 2번(공통 설정과 함수)을 먼저 실행한 뒤 불러와야 합니다.
